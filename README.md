# Élan Fitness

Site web de la salle de sport Élan Fitness, à Casablanca. C'est un projet de formation : le site était une seule page et je l'ai transformé en site de plusieurs pages.

## Les pages

- Accueil (`index.html`)
- À propos (`propos.html`)
- Programmes (`programmes.html`)
- Contactez-nous (`contact.html`)

Le menu est le même sur toutes les pages et la page en cours est mise en couleur.

## Lien du site

- **Site en ligne (GitHub Pages)** : https://aymenlaoudi.github.io/Brief01/index.html
- **Dépôt GitHub** : https://github.com/aymenlaoudi/Brief01

## Structure du projet

```
.
├── index.html          # Page d'accueil
├── propos.html         # Page À propos

├── contact.html        # Page Contactez-nous

```
